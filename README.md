A program that writes one funny line to `/output/entry.txt` — a one-line roast of the fridge. An entry for [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) on make.fun.

## The line

> The fridge light judges my 2 a.m. snacks, yet it has never once paid rent or done the dishes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (93 characters, within the 1–199 gate) and nothing else.

- `main.py` — the entry program: writes the line to `entry.txt`.
